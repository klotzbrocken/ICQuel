## ICQuel 1.0

First release of ICQuel, a retro-styled chat companion for macOS.

- Just the feeling: pick any ID and nickname, a few fake friends write to you. No account, no server.
- Four looks: Windows classic, macOS classic, Aqua and modern. Themes are plain folders and can be imported.
- Optional AI chat (bring your own API key) and optional iMessage support (local, read-only, only the conversations you choose).
- Universal app for macOS 13+, signed and notarized. Updates come through Sparkle (Check for Updates in the app menu).

Fan project, not affiliated with ICQ or any messenger company. Part of the [Retro Family](https://myretromac.app/retro-family).
