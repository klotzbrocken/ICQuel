ICQuel 1.1

  • Preferences apply immediately; the new Privacy page explains every permission and every feature that sends text somewhere.
  • OpenAI support next to Anthropic, with a model drop-down filled from the provider.
  • iMessage: optional group chats, pictures / GIFs / files in the chat, delivered and read status.
  • Chat extras: GIF search (Powered by GIPHY), Photos picker, Find, ActiveList, Forward, Request Chat, Random Chat, status messages, contact notes, icquel://status/... for Focus automations.
  • Optional away helpers: auto-reply with guardrails, "What did I miss?" summary, reply drafts.
  • WhatsApp (experimental, off by default, unofficial): see Preferences > Bridge.

ICQuel 1.0

  • First release: a retro-styled chat companion for macOS (just the feeling, no account, no server).
  • Four looks: Windows classic, macOS classic, Aqua and modern; import your own skins.
  • Optional AI chatbots (bring your own API key) and optional iMessage support (local, read-only, your choice of conversations).
